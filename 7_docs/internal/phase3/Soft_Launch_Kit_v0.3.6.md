## 安装引导

1. 下载安装包
2. 双击运行 omnimemora
3. 浏览器会自动打开 dashboard
4. 执行：`omnimemora connect codex`（或 claude）
5. 正常使用你的 AI 工具
6. 回到 dashboard 看 token savings

**必须额外说一句：**

```
你不用改变任何使用方式，正常用就行。
```

1. 你觉得这个工具是干嘛的？

3. 你会继续用吗？（只能选：会 / 不会）

## 必须盯的3个关键信号

### 1. 首屏理解

用户第一反应是什么？

如果他说：
- "这是 memory 工具" ❌
- "这是上下文优化" ❌

👉 说明表达失败

### 2. 信任问题（重点）

用户问："这个 savings 是怎么算的？"

👉 一旦问，说明不信

### 3. 二次打开

用户有没有主动再打开 dashboard？

👉 这是最真实指标
