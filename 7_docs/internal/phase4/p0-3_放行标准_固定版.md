# P0-3 放行标准（固定版）

适用范围：OpenClaw 集成验收。

放行规则（必须同时满足）：

1. 自动化验证 PASS
2. 手工验证 PASS

判定：`自动化 PASS && 手工 PASS` 才允许发布。

## 前置 6 条（必须真）

1. 配置写入成功（Configured）
2. MCP 握手成功（Connected）
3. tools/list 可见 memory 工具
4. 至少一次 memory.write 成功
5. 至少一次 memory.search/context/recall 成功
6. `/metrics` savings 非 0（total 或 today/week/month 任一非 0）

## 第 7 条（稳定复现，核心放行条款）

同类真实任务复跑 3 次，以下同时成立：

1. 无 MCP 启动错误
2. 工具调用持续非 0
3. savings 持续增长，非偶发一次
4. 后半段 savings >= 前半段 1.3x
5. 前半段 savings >= 300 tokens
6. `memory.search/context/recall` 调用次数差异 <= 30%
7. Dashboard 状态全程为 `Memory Tools Active`

任一条失败即不放行。
