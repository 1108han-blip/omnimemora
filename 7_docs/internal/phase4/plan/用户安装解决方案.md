# 三、BOOTSTRAP（入口必须做完全部流程）

## 主流程（唯一入口）

```bash
onAppStart():

    port = resolvePort()

    if not runtimeRunning(port):
        startRuntime(port)

    waitUntilHealthy(port)

    openDashboard(port)

    agents = detectAgents()

    selectedAgents = resolveAttachStrategy(agents)

    attachAgents(selectedAgents)

    runAutoVerify()
```

## 端口策略

```bash
resolvePort():

    if 8765 free:
        return 8765

    for port in [8766, 8767, 8768]:
        if free:
            return port
```

# 四、AGENT DETECTION（统一检测逻辑）

```bash
detectAgents():

    agents = []

    if exists("%USERPROFILE%\\.codex"):
        agents.append("codex")

    if exists("%USERPROFILE%\\.config\\claude-code"):
        agents.append("claude")

    if processRunning("openclaw"):
        agents.append("openclaw")

    if exists("%APPDATA%\\Cursor"):
        agents.append("cursor")

    return agents
```

---

# 五、连接策略（核心决策树）

```bash
resolveAttachStrategy(agents):

    if agents == 0:
        return []

    if len(agents) == 1:
        return agents   # 自动接入

    if len(agents) >= 2:
        return showQuickSelectUI(agents)
```

# 七、AUTO ATTACH（统一执行）

```bash
attachAgents(agents):

    for agent in agents:

        if agent == "codex":
            attachCodex()

        if agent == "claude":
            attachClaude()

        if agent == "openclaw":
            attachOpenClaw()

        if agent == "cursor":
            attachCursor()
```

---

## Codex

```bash
attachCodex():

    path = "%USERPROFILE%\\.codex\\config.json"

    config = readJson(path)

    config["omnimemora"] = {
        "endpoint": runtimeEndpoint()
    }

    writeJson(path, config)

    restartProcess("codex")
```

---

## Claude

```bash
attachClaude():

    path = "%USERPROFILE%\\.config\\claude-code\\config.json"

    config["memory"] = {
        "provider": "omnimemora",
        "endpoint": runtimeEndpoint()
    }

    writeJson(path, config)

    restartProcess("claude")
```

---

## 进程重启

```bash
restartProcess(name):
    kill(name)
```
