## 1. 角色分工（固定）

1. OpenClaw：
   - 文档整理类工作（提纲、结构化收口、对齐检查）
   - 审计与测试类工作（状态、配置合规、健康检查、回归验证）
2. Claude Code：
   - 代码写入
   - Bug 修理
   - 最小改动实现与测试通过
3. Codex（总控）：
   - 任务拆分与优先级管理
   - 结果复核与风险把关
   - 代码与系统文档同步落盘
   - 最终交付结论

## 2. 执行流水线

1. Codex 定义目标与验收标准。
2. Claude Code 执行代码修改并回报变更文件与测试结果。
3. OpenClaw 执行审计/测试并生成结构化结论。
4. Codex 复核两侧结果，必要时追加一轮修复。
5. Codex 同步更新主仓库 `7_docs` 文档并出最终结论。

## 3. 强制验收门禁

所有“已完成”结论必须同时满足：

1. 代码侧：变更可编译，相关测试通过。
2. 主体侧：对应主体自检/validate 通过。
3. 文档侧：主仓库 `7_docs/internal/phase4/plan` 同日更新。

任一未满足，状态只能是“进行中”。
