### 1.3 故障快速分流 (必做)

| 故障分类 | 包含场景 | 处理预案 |
|---------|---------|---------|
| **A 类: 安装失败** | 系统拦截 / 权限 / 浏览器没自动打开 | 准备截图引导 + 远程协助准备 |
| **B 类: connect 失败** | CLI 路径问题 / 连接不到 runtime / agent 未识别 | 准备诊断脚本 / 日志收集指引 |
| **C 类: 价值感知失败** | 看不懂 dashboard / 不信 savings / 感觉没差别 | 准备 1 分钟讲解视频 / 图文说明 |

- [ ] ≥5 人成功走完完整流程
