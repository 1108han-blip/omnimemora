# Cloud Reset Batch 1

## 目标

本批不是“修旧云端”，是“云端重置与去污染”。

核心目标：把云端口径和当前产品基线重新对齐。

- Local：`8765` memory plane，`18011` product ingress，保持执行真相
- Cloudflare：唯一外部域名入口与轻控制面
- Railway：candidate state / 轻异步作业 / 低成本持久化
- 禁止：云端主 memory plane、云端主 compile path、旧命名继续污染当前入口

## 职责模型（固定）

### Cloudflare

- `doloclaw.com` 正式入口
- control-plane API / auth / tenant / billing / policy access
- candidate fetch entry

不承担：

- 主 memory plane
- 主 compile engine
- `/memory/*` 主写读删查

### Railway

- recommendation candidate snapshots / manifests / lightweight state
- 轻量后台聚合作业

不承担：

- `/memory/*` 主路径
- 主 compile path

### Local

- recommendation active/fallback 保持本地
- 本地 promotion 才能改变 active 生效
- 离云可用保持不变

## Batch 1 执行边界

### 必做

1. 删除旧云端污染面（prototype/archive/临时现状文档）
2. 清理 active 入口中的旧命名
3. 建立 cloud candidate source 最小骨架：
   - Cloudflare candidate pointer fetch
   - Railway candidate snapshot/state fetch
   - 本地 loader：active 不变，candidate 可选补位

### 不做

- 不在本批实现完整云端候选管理后台
- 不在本批做远端全流程同步
- 不在本批改变本地 active 优先级

## 验收口径

### 结构

- 删除旧 prototype 后，`6_console/demo-dashboard` 不受影响
- recommendation 本地链路不回归

### 文档

- active docs 不再把云端 memory adapter 当当前事实
- active docs 不再把旧命名作为当前产品名词
- `doloclaw.com` 明确为当前唯一正式域名入口

### 非回归目标

- `18011 / 8765 / 5173` running reality 不因本批清理而改变
