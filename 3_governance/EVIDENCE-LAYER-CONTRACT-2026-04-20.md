## Completed Outcomes

### 1. Unified Request Evidence Truth

`GET /debug/request_evidence?request_id=...` is now the single entry point for overview下半区三模块联动。

**返回结构**:
```typescript
interface RequestEvidence {
  request: {
    request_id: string;
    timestamp: string;
    raw_agent_id: string;       // 原始值，仅 diagnostics 追溯用
    agent_family: string;         // canonical，已 normalize
    task_type: string;
    query_summary: string;
  };
  status: {
    request_status: RequestStatus;  // success | warning | failed | bypassed | not_used
    bypass: boolean;
    failure_stage: string | null;
    failure_reason: string | null;
  };
  context: {
    before_tokens: number;
    after_tokens: number;
    saved_tokens: number;
    savings_ratio: number;
    selected_memory_count: number;
    dropped_memory_count: number;
    selected_memories: MemoryEntry[];
    dropped_memories: MemoryEntry[];
    context_state: ContextOptimizationState;  // optimized_visible | traffic_but_no_optimization | bypass_or_not_applicable
  };
  chain: {
    nodes: RequestEvidenceNode[];
    trace_id: string;
  };
}
```

**旧接口保留，过渡期不删除**:
- `GET /debug/context_diff` — 仍可用，前端已不依赖
- `GET /debug/call_chain` — 仍可用，前端已不依赖

### 2. Canonical Agent Identity

`agent_family` 在后端统一做 canonicalization，不接受 raw/internal id 进入默认用户路径。

**Mapping 规则** (`AGENT_ID_MAPPING`):
```
openclaw-agent / openclaw        → openclaw
claude-code / claude-code-cli    → claude_code
codex / codex-cli               → codex_cli
(未经映射的原始值)               → 直接作为 canonical（adapter 不重新定义）
```

**返回字段**:
- `agent_family`: canonical，用于所有默认显示路径
- `raw_agent_id`: 原始 meter agent，仅 diagnostics 追溯用，前端不默认显示

### 3. 产品级节点 Contract（固定 8 节点）

`chain.nodes` 现在是固定 8 个产品级节点，不再暴露内部 stage 名称（如 `engine_total`、`filter`、`pack`）。

**节点定义**:
| ID | Label | 触发条件 | Status 推导 |
|----|-------|----------|-------------|
| `app_request` | App Request | 始终 | success |
| `entry_18011` | Entry 18011 | 始终 | success |
| `route_decision` | Route Decision | task_type 已确定 | task_type != "unknown" → success |
| `memory_recall` | Memory Recall | 有候选记忆 | selected_count > 0 → success; ==0 但 task 确定 → warning |
| `context_pack` | Context Pack | 有打包记忆 | packed_count > 0 → success; ==0 但有候选 → warning |
| `compile_or_bypass` | Compile / Bypass | bypass 标志 | context_bypass=true → bypassed; 否则 savings_ratio > 0 → success |
| `upstream_forward` | Upstream Forward | 有远程调用 | remote_used > 0 → success; 否则 not_used |
| `response_recorded` | Response Recorded | 始终 | success |

**Duration 来源**: 从内部 call chain stages 聚合（`_stage_duration()`）。
**注意**: `response_recorded` 的 duration 映射到 `engine_total`。

## Evidence Layer 定位规则

1. **默认用户路径**: 只能看到 `agent_family`（canonical）、产品级节点标签、`context_state`、token savings 数据
2. **Diagnostics 追溯**: `raw_agent_id`、内部 stages、原始评分字段仅在 diagnostics 子层可用
3. **产品语义优先**: 节点 ID 是产品级概念（`memory_recall`），不是内部实现（`filter` + `dedup`）
4. **节点固定**: 8 节点是 fixed contract，后续图形化（节点灯、链路图）直接映射，不需重新定义
