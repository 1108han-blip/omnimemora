OMNIMEMORA CONTROLLED BETA RELEASE NOTES
Package version: {{PACKAGE_VERSION}}

Highlights
- Desktop beta package foundation for local-first OmniMemora usage.
- Release manifest is published at https://doloclaw.com/releases/latest.json.
- Product entry remains local: 5173 control surface, 18011 product ingress, 8765 internal memory plane.
- Desktop service controls now show each local product port and status, so stop/restart/start failures are visible in the app instead of looking like a silent port issue.
- Fixes Claude Code route enablement by keeping desktop-managed services on the installed runtime agent mode file.
- Attached agents repair local product startup before falling back to direct upstream when 18011 is unavailable.
- Desktop App checks the official release manifest, surfaces new versions in-app, downloads and verifies the installer, then hands off installation to the OS.
- Agent control refresh waits long enough for the local product control endpoint after a user clicks "Use OmniMemora".
- Adapter proxy responses strip transport headers that can break streamed client connections.
- Cloud policy updates remain candidate-only and do not auto-promote over local active policy.

What this beta is for
- Verify real desktop installation and startup behavior.
- Collect request_id and error_code based feedback from real users.
- Validate whether local-first token/context value is understandable to target users.

What this beta is not
- Not an open-source release.
- Not a public production launch.
- Not a commercial license.
- Not a silent forced update channel.
