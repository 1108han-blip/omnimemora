Minimal console for tenant-level usage, savings, and access state.

This page is the smallest usable SaaS surface for OmniMemora. It is intentionally narrow: read tenant usage, view recent requests, inspect savings trend, and run a smoke query through the same `/memory/query` path that now supports OmniMemora API keys.

Default target is the local adapter at http://127.0.0.1:8000. Use this console for controlled evaluation, not as a full admin panel.

Console boundary

This console is intentionally small. It exists to prove the SaaS loop, not to replace a full control plane. Billing is currently frozen — the active commercial path is free trial first.

  • Included now: tenant summary, usage cards, recent requests, savings trend, smoke query.
  • Not included: billing (frozen), tenant administration, policy editing, organization RBAC, write/delete controls.
  • Trial next step: submit the contact form to receive a free trial API key automatically.
