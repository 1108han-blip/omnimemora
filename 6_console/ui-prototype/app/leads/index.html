API Usage

This page documents the API endpoints. Use them directly if you prefer code over UI.

Authentication

All requests require: Authorization: Bearer <OPERATOR_SECRET>
GET /api/leads
Returns the list of leads. Optionally filter by status with a query parameter.
PATCH /api/leads
Update lead status (e.g., status: "reviewed" or status: "archived"). Include the lead id in the request body.

Boundary

This inbox is intentionally small. Know what it is, and what it is not.

  • What it is: a minimal private inbox for reviewing leads and documenting API usage.
  • What it is not: a CRM, billing system, tenant admin panel, or analytics dashboard.
  • Credentials are not stored; you must provide the operator secret on each page load.
