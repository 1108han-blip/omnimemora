# 1_architecture/

**Purpose:** 技术结构映射与接口契约层

---

## 本层职责

本层只负责：
- 将 `0_blueprint/` 的结构映射到工程实现
- 定义技术接口契约（API / Schema / Store interface）
- 记录当前实现状态与模块边界

本层不负责：
- 定义产品
- 定义产品边界
- 定义系统角色
- 重新解释 blueprint

---

## 文件规则

### 允许

- 技术架构映射
- 接口契约
- 当前实现落点
- 模块边界

### 禁止

- 产品定义
- 商业定位
- 云/本地路线再定义
- 旧架构复活

---

## 治理规则

- `0_blueprint/` 是唯一权威来源
- 本层所有文件都必须可追溯到 `0_blueprint/`
- 若与 `0_blueprint/` 冲突，以 `0_blueprint/` 为准
